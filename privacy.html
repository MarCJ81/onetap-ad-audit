개인정보 처리 방침

최종 갱신 2026-11-22 · 서버 없음 · 계정 없음 · 결제 없음

1. 수집하는 개인정보

없습니다. 회원가입·로그인·결제가 없고 운영자 서버가 없습니다. 광고 캠페인 CSV와 표에 입력한 값은 이용자의 브라우저 안에서만 계산되며, 앱이 그 내용을 운영자에게 보내지 않습니다.

2. 저장 위치와 항목

캠페인 표(이름·매체·상태·예산·지출·노출·클릭·전환·매출), 목표 ROAS/CPA, 언어 설정이 브라우저 localStorage(키 onetap.adaudit.v1)에 저장됩니다. 같은 브라우저에서 다시 열었을 때 이어 쓰기 위한 것이며, 다른 곳으로 보내지 않습니다.

Pro 기능에서 입력한 OpenAI·Gemini·Claude API 키는 localStorage(키 onetap.adaudit.keys)에만 저장됩니다. 키는 화면에 다시 표시하지 않고, 아래 4항에서 설명한 제공자 호출에만 쓰입니다.

3. 광고 데이터의 성격

이 앱이 다루는 것은 광고 캠페인의 성과 수치와 캠페인 이름입니다. 고객 이름·전화번호·이메일 같은 개인정보를 입력하도록 요구하지 않습니다. 캠페인 이름에 개인정보가 들어 있다면 CSV를 넣기 전에 해당 열을 지우시길 권합니다. 지출·매출 같은 재무 수치는 브라우저 밖으로 나가지 않습니다.

4. 외부 전송

무료 모드에서는 외부 전송이 0건입니다. 폰트·아이콘·스크립트를 포함한 모든 파일을 앱과 함께 배포하므로, 페이지를 열 때 다른 서버로 요청을 보내지 않습니다.

Pro 기능은 이용자가 “카피 3안 생성”을 누를 때만, 저장된 키로 선택한 제공자(OpenAI·Google Gemini·Anthropic Claude)의 API에 캠페인 성과와 프롬프트를 직접 전송합니다. 운영자 서버를 거치지 않으며, 그 시점부터는 해당 제공자의 약관·개인정보 처리 방침이 적용됩니다. 전송을 원하지 않으면 무료 규칙 엔진만 쓰시면 됩니다.

5. 쿠키·추적

쿠키를 쓰지 않습니다. 분석 도구·광고 픽셀·외부 트래커를 넣지 않으며, 이용 기록을 수집하지 않습니다.

6. 보관과 삭제

저장된 값은 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다. 앱의 Pro 화면에서 삭제를 누르면 키만 지울 수 있고, 행 삭제로 캠페인을 지울 수 있습니다. 내려받은 CSV·MD 파일은 이용자가 직접 관리합니다. 공용 PC에서는 사용 후 사이트 데이터를 지우거나 시크릿 창을 쓰시길 권합니다.

7. 제3자 제공

운영자는 이용자의 데이터를 받지 않으므로 제3자 제공·위탁이 없습니다. Pro 호출은 이용자와 제공자 사이의 직접 통신입니다.

8. 시뮬레이션 결과의 성격

예상 절감액·추가 매출·ROAS는 최근 30일 실적과 화면에 적힌 가정(증액분 효율 85%, 캠페인당 최대 +80% 등)으로 계산한 추정치입니다. 실제 광고 성과를 보장하지 않습니다.

9. 문의

이 앱은 정적 파일로 배포되며 운영자에게 개인정보가 전달되지 않습니다. 문의·오류 제보는 배포 저장소의 이슈로 남겨 주세요.

Privacy (English)

Last updated 2026-11-22 · no server · no account · no payment

This app collects no personal data. Campaign figures you paste or type stay in your browser and are computed locally. Campaign data, targets and language are stored in localStorage (onetap.adaudit.v1); Pro API keys are stored only in onetap.adaudit.keys.

There are no cookies, analytics, pixels or external requests in free mode. When you press “Write 3 variants” in Pro, the campaign metrics and prompt are sent directly from your browser to the provider you chose (OpenAI, Google Gemini or Anthropic Claude) using your key. No operator server is involved. Clearing site data deletes everything stored locally; downloaded CSV and Markdown files are yours to manage.

Projected savings, added revenue and ROAS are estimates from the last 30 days and the stated assumptions, not a guarantee of future performance.
